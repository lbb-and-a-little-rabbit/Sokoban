# 新增经典关卡

关卡编号 15–34 使用 David W. Skinner（2000）的 Microban 1–20。原编号 15–20 顺延为 35–40。

- 作者原站：http://users.bentonrea.com/~sasquatch/sokoban/
- 归档：http://www.sneezingtiger.com/sokoban/levels/microbanText.html
- 本次下载的文本镜像：https://github.com/Mason363/NumPlay/blob/main/games/sokoban/levels/microban.txt

仅转换字符（$ → b、. → x、@ → p、* → B、+ → P），并用空格补齐行宽，未改变谜题布局。

## 扩充至 100 关

在现有关卡后追加 Microban 21–79，共 59 关，对应游戏编号 41–99。总计 100 关（编号 0–99），原编号 0–40 的布局与顺序不变。来源与转换规则同上。
